# Dingtalk-Download
Download Dingtalk replays using python + fiddler and integrate/transcode them into MP4.

## Usage

0. Open fiddler

1. Play the Dingtalk group replay you want to download

2. Find an m3u8 file and copy it

3. Run `downm3u8.py` and paste the m3u8 file address

4. After execution, an MP4 will be generated in `./download/`
